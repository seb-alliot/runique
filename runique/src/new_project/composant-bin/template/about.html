Runique Framework

A Django-inspired web framework built on Rust's performance and safety.

Key features

  • Strongly typed forms and validation
  • Django-like project structure
  • Built on Axum, Tera and SeaORM
  • First-class async support with Tokio

Why Runique?

Runique brings Django's architecture patterns to the Rust ecosystem. If you like Django's "batteries included" philosophy but want Rust's performance and type safety, Runique is for you.
