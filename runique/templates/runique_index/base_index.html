🦀 Bienvenue sur Runique

Projet de framework web en rust

Caractéristiques

  • ✨ Inspiré de Django pour une expérience familière
  • ⚡ Construit sur Axum pour des performances optimales
  • 🛡️ Gestion d'erreur sophistiquée avec pages de debug
  • 📝 Support de Tera pour le templating
  • 🗄️ Intégration SeaORM optionnelle
  • 🔧 Configuration flexible et intuitive

Commencer

  • cargo new my-app
  • cd my-app
  • cargo add runique
