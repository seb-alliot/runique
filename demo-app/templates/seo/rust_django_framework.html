Runique : un framework web Rust inspiré de Django

Runique apporte l'expérience de développement de Django à Rust. C'est un framework web Rust complet : administration typée, formulaires typés, modèles et migrations, authentification et sécurité CSRF/CSP intégrée, construit sur Axum, SeaORM et Tera.

Commencer → crates.io GitHub

Pourquoi un framework de type Django en Rust ?

Rust dispose de briques web rapides et de bas niveau, et aussi de frameworks complets : Cot s'inspire de Django, Loco de Rails. Runique suit l'approche de Django : au lieu d'assembler à la main un ORM, un moteur de templates, une administration et une couche de formulaires, vous les obtenez intégrés et guidés par des conventions, en gardant la sûreté de typage et les performances de Rust.

Une administration typée

Comme l'admin de Django, Runique sert une interface CRUD complète à partir de vos modèles avec le builder typé ModelAdmin : colonnes de liste, recherche, filtres latéraux, pagination, actions groupées et contrôle des droits. Voir la documentation de l'admin.

Formulaires et modèles typés

Déclarez un modèle une fois : Runique en dérive l'entité SeaORM, la migration SQL et un formulaire typé avec validation côté serveur. En savoir plus sur les formulaires et les modèles et la macro model!.

Tout est inclus : authentification, sessions, sécurité

L'authentification, les sessions persistantes, la réinitialisation du mot de passe, la protection CSRF, une CSP configurable et la validation des hôtes sont fournies d'origine. Découvrez l'authentification, les sessions et les middlewares de sécurité.

Runique — a Rust web framework inspired by Django

Runique brings the Django developer experience to Rust. It is a batteries-included Rust web framework with a typed admin panel, type-safe forms, database models and migrations, authentication and built-in CSRF/CSP security — built on Axum, SeaORM and Tera.

Get started → crates.io GitHub

Why a Django-like framework in Rust?

Rust has fast, low-level web building blocks, and full frameworks too: Cot is inspired by Django, Loco by Rails. Runique follows the Django approach: instead of wiring an ORM, a templating engine, an admin and a form layer by hand, you get them integrated and convention-driven, while keeping Rust's type safety and performance.

A typed admin panel

Like the Django admin, Runique serves a full CRUD back office from your models with the typed ModelAdmin builder: list display, search, side filters, pagination, bulk actions and permission checks. See the admin documentation.

Type-safe forms and models

Declare a model once and Runique derives the SeaORM entity, the SQL migration and a type-safe form with server-side validation. Read about forms and models and the model! macro.

Batteries included: auth, sessions, security

Authentication, persistent sessions, password reset, CSRF protection, a configurable CSP and host validation ship in the box. Explore authentication, sessions and security middleware.

FAQ

Is there a Django-like web framework for Rust?

Yes, there are several. Runique is inspired by Django, and Cot models its API after Django too; both are batteries-included frameworks with an admin panel. Loco, for its part, is inspired by Rails.

Does Runique have an admin panel like Django admin?

Yes. It generates a full CRUD admin from your models, with search, filters, bulk actions and permissions.

Which Django alternative should I choose in Rust?

Runique and Cot both follow the Django approach. The right choice depends on your needs: the Runique vs Cot page puts them side by side, feature by feature.
